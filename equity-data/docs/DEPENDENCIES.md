## 软件运行依赖

核心使用 Python 3.11+、SQLite、JSON、TOML 和 HTTP 传输；数据库与原始目录位于项目数据目录，可备份迁移。具体安装命令与固定版本见项目依赖文件和 README。

交易日历实际复用 `exchange_calendars`（包括其 pandas 依赖）与 IANA 时区数据库；Windows 需要可用 `tzdata`。未安装时记录缺口，不用工作日近似填充。包升级可能改变旧日期结果；保存版本和生成原始 JSON，升级后新增版本，不覆盖旧数据。

Alpaca 与 FRED API 密钥仅从指定环境变量读取。用户的真实联系邮箱可以配置给 SEC；示例代码/测试不保存任何真实密钥。公开 FRED CSV 模式是当前快照演示，不能解除宏观 vintage 缺口。所有 mock 测试样本只在临时目录生成，不能混入交付的真实观测库。
