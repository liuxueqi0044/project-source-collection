# V5 阶段 A：变化与语义边界

生产模块为 `competition/change_detector.py`、`events.py`、`linker.py` 和 `discovery.py`。均为无网络、无数据库写入的纯函数；采集器保存原文，runner 提供原文版本、取得流水和身份审核状态。

## 快照和变化

支持静态 HTML/CSS、RSS/Atom、配置路径的 JSON 及纯文本；不支持的媒体、空页面、错误响应、登录墙或找不到正文选择器会明确拒绝。HTML 正文保留 p/div/table 中的可见文字、数字、符号和否定词，移除脚本、样式与默认导航；选择器和观察环境进入配置指纹。

结果独立区分 `baseline`、`no_change`、`noise_only`、`changed`、`rejected`。原文变化不等于业务事件。选择器、解析版本或观察环境改变要求重新解析两份原文，不直接判定业务变化。

数值规则仅接受明确单值；保留负号、括号负数、百分比和来源金额倍数。美元符号没有配置中的已知币种时拒绝；范围、歧义符号、不匹配括号及币种冲突不输出数值。不会沿用前一版本数字。

价格变化须有两个成功快照以及相同的产品、地区、规格、数量、税费、付款周期、价格类型、登录环境、币种和单位。观察环境来自配置并注明，不冒充页面陈述。首次取得只是基线；未知环境只产生候选。缺少官方事件时刻时保留前后观察区间，不把取得时间写成发生时间。

## 事件合同

输出 `events`、`candidates`、`issues`。二者都是来源主张，`events` 为字段齐备的 `extracted_fact`，仍是 `source_claimed_unverified`，并非独立核验结论；候选不计入事实。绝不生成利润影响或交易判断。

事件字段包含主体、六类事件、行动、对象、业务/地区/客户范围、阶段、公开/事件/观察时间、数值/币种/单位/期间、证据、未知项及解析版本。元信息无法确认则为空或 `unknown`。主体未核实、范围缺失、证据缺失、歧义数值进入候选。

| 类型 | 阶段 A 规则 | 未完成部分 |
|---|---|---|
| 业绩/指引 | 明确指引动作句；可配置源文捕获数值和期间 | 通用复杂财务表格、完整财务预测语义 |
| 产品 | 明确发布/退出陈述 | 从失败页面推断下架（禁止） |
| 价格/条款 | 两快照可比价格；其他条款为候选 | 成交价、复杂促销、套餐组合 |
| 合同/客户/合作 | 明确合同和合作动作；可捕获事项编号 | 从签约推断履约或目标丢单（禁止） |
| 产能/渠道/区域 | 明确计划、开厂、投产动作并保留阶段 | 从招聘、许可推断投产（禁止） |
| 监管/并购 | 明确提议、批准、完成、取消陈述 | 法律判断及所有监管来源 |

默认通用词法规则只能捕获有限的英文动作句，往往缺少业务或客户范围，必须如实进入候选。网站/行业可通过 `event_rules` 配置命名捕获 `action,object,business_scope,geography,customer_segment,event_identifier,contract_id,project_id,product_id,amount,currency,unit,period,event_time,status`；所有值须来自匹配的原文，不能在规则中预填数字答案。金额和单位变化必须重新解析。

RSS 每条项目保留自己的公开时间。保存 feed 内容不等于保存链接文章全文。HTML/RSS/JSON 的复杂嵌套、转义与区域定位仍须通过持久层对原始字节的独立证据检查；无法匹配应拒绝该派生记录。

跨来源归并只允许明确事项/合同/项目/产品标识；否则保留来源主张并标记可能重复。标题相似、同日发布不产生自动归并键。明确事项编号的数值更正沿用逻辑事项身份，持久层追加事实版本；不同合同编号保留不同事件。

## 目标关联与发现

关联必须引用精确事件和竞争关系版本。产品/业务、地区、客户范围按明确值匹配，不自动扩展国家层级、同义词或整个公司。范围未知进入待核验，硬不重叠进入排除。只有已确认、有证据、在事件时间有效的关系与已提取事实才可进入核心关联；缺少公开/发生时间不能用最近取得时间替代。关联只表示竞争范围交集，不推断财务影响。

候选发现限于已保存原文和登记主体名称/别名；明确竞争语句、共同出现分别标注，均不自动确认。重名保持身份歧义；未知企业名解析、跨网站搜索是缺口。达到候选上限明确 `truncated=true`，不声称完整。

## 验收解释

`tests/test_competition_semantics.py` 是合成行为回归，不是真实事件准确率。真实保留样本另存 `reports/v5/semantic_holdout`，先冻结代码及独立参考标签，再运行提取器。候选召回、完整事实召回、核心简报精确率分别报告；零完整事实时精确率未定义，不能写成 100%。
