# Curated code backup

First-party source, documentation, tests, dependency lockfiles and configuration templates only.

Excluded: VM disks and installation media, upstream packages, dependencies and runtimes, caches, build/distribution products, private state and evidence, actual credentials and local environment configuration.

Stock databases, stock backups, exports and reports were not read, copied, modified or deleted. Minecraft build and run directories were not accessed.

Potential secret matches were excluded without recording their values. Original files were not modified.
