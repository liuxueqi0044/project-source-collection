# Internal implementation contract

Python 3.11+. Root owns CLI, HTTP transport, public sample manifests, integration, docs/reports. All paths relative to project root unless configured.

Core module `equity_data/store.py`: `Store(root: str|Path)` uses root/data.sqlite3 and root/raw. Public `db` sqlite connection row_factory=Row. `now_utc()` returns UTC ISO string. `put_raw(content: bytes, *, source: str, url: str, media_type: str='application/octet-stream', retrieved_at: str|None=None, metadata: dict|None=None) -> dict` returns {raw_id, sha256, path, retrieved_at, source, url}. Save exact bytes by hash; retrieval metadata retains each successful acquisition. `put_record(dataset: str, record_key: str, data: dict, *, source: str, raw_id: str, company_id: str|None=None, security_id: str|None=None, published_at: str|None=None, publication_precision: str='unknown', publication_timezone: str|None=None, available_at: str|None=None, availability_basis: str='unknown', period_start: str|None=None, period_end: str|None=None, event_date: str|None=None, source_locator: str|None=None, unit: str|None=None, currency: str|None=None, quality: str='unverified', knowledge_type: str='fact_observation', parser_version: str='1', supersedes: str|None=None) -> str` returns record_id. Retrieval time inherited from raw. Same source/dataset/key/version semantic payload idempotent, keep changed versions. Must not use report end as availability. `query(dataset, *, as_of: str|None=None, known_at: str|None=None, company_id=None, security_id=None, latest=True) -> list[dict]` returns full rows with data dict. as_of filters disclosed/available time, unknown excluded; known_at filters acquired time. Same-as-of tied conflicting versions fail closed if correction not evidenced until later acquisition. `issue(code, message, *, dataset=None, company_id=None, security_id=None, severity='warning', details=None)`; `checkpoint(key, value=None)` get/set JSON; `close()`.

Dataset names: company_profiles, securities, identity_history, calendar_sessions, security_status, market_rules, daily_bars, adjusted_bars, corporate_actions, financial_facts, filings, documents, guidance, analyst_estimates, earnings_actuals, event_calendar, benchmark_bars, relations, industry_metrics, macro_observations, policy_documents, news, research_materials.

Root HTTP `equity_data/http.py`: `HttpClient(store, user_agent='EquityDataResearch/0.1', requests_per_second=2, max_attempts=3, timeout=40)`; `fetch(url, *, source, headers=None, params=None, refresh=True) -> (bytes, raw_dict)`. On HTTP errors record issue and raise; rate limit per host, retry only transient, store raw only success; credential query parameters redacted in provenance. Cache refresh=False may return prior successful payload. SEC requests require configured contact identity, no made up address. Config standard Python TOML parsed root. Adapters must use client fetch to preserve evidence.

SEC module API `collect_sec(store, client, config: dict) -> dict` where config has start/end ISO dates, securities [{company_id:'sec:0000320193',security_id:'local:us:aapl-common',cik:'0000320193',symbol:'AAPL',exchange:'XNAS',currency:'USD',security_type:'common_stock'}], sec {user_agent, forms:[...], max_documents_per_company:6, download_exhibits:true, historical_submissions:true}. Must get submissions older files for period, companyfacts all concepts (filter filing date to configured range), documents actual primary HTML and 8-K exhibits if available; use SEC acceptance for availability and conservative end-of-day on filing-date-only. Limit selected docs honestly reported. Preserve company-only facts without assigning to common stock arbitrarily. No network in tests.

Provider module API `collect_alpaca(store, client, config)->dict`, `collect_fred(store,client,config)->dict`, `collect_calendar(store,client,config)->dict`. Each returns counts/status/reason. Missing credentials logs gap, no fake successful data. Alpaca raw adjustment, explicit feed/coverage; FRED vintages as dates conservative next-day cutoff; calendar package generated material must unknown public availability (can retrieve now).

No global app/environment modifications. All tests stdlib unittest or pytest. Tests may create synthetic fixture data only in temporary directories clearly marked, never delivered as observed source data. Dataset dictionaries in docs record distinction implementation vs connected/validated.
